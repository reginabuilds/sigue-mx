# Rehearsal MX — Week 6

Academic MVP for Business Bending Week 6. The slice tests family adaptation when a preparedness plan breaks.

## Stack
- Next.js + TypeScript
- CSS 3D simulation (labeled)
- Deterministic adaptive logic (labeled simulated AI)
- Browser SpeechSynthesis voice layer
- No personal data, no auth, no database required for this demo

## Run
npm install
npm run dev

## Safety
This is a simulated academic rehearsal. It is not emergency advice, does not replace Protección Civil or school protocols, and does not collect real family information.
