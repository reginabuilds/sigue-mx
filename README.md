# SIGUE MX

**Del resultado al siguiente paso.**

Week 5 adversarial MVP: Detection → Interpretation → Action (Treatment Navigation vacuum).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Safety

This is an academic demo. It does not diagnose, prescribe, verify medical status, invent live provider availability, or invent prices. All route resources are explicitly labeled as simulated.

Optional: set `OPENAI_API_KEY` to enrich interpretation text. Without it, a deterministic safe fallback is always used.
